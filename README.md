# מעקב החזר מנוי - מכבי חיפה 🟢⚪

אתר קטן למעקב אחרי כמה "החזרתם" מהמנוי (2,000 ₪) בפופקורן, גומי ושתייה בכל משחק בית של מכבי חיפה.
כמה משתמשים (משפחה/חברים) יכולים לעדכן ולראות את אותם נתונים במקביל, בזכות אחסון משותף ב-Firebase.

## מה יש באתר

- סה"כ הוחזר, אחוז מתוך המנוי, וכמה נשאר עד כיסוי מלא
- פירוט וגרף לפי סוג פריט (פופקורן ₪20 / גומי ₪15 / שתייה ₪10)
- היסטוריית משחקים - לוח המשחקים של העונה טעון מראש (עדכני ל-26.7.2026), ואפשר להוסיף/למחוק משחקים
- כל עדכון נשמר ב-Firestore ומופיע אצל כולם בזמן אמת

אין צורך בשרת או בבנייה (build) - זה אתר סטטי (HTML/CSS/JS) שרץ ישירות בדפדפן.

---

## שלב 1: הקמת פרויקט Firebase (חינמי)

1. גשו ל-https://console.firebase.google.com ובחרו **"Add project"** (הוסף פרויקט).
2. תנו שם לפרויקט (למשל `maccabi-haifa-refund`) ולחצו הבא עד שהוא נוצר.
3. בתפריט הימני: **Build -> Firestore Database -> Create database**.
   - בחרו מצב **Production mode** (נגדיר כללי הרשאה בעצמנו).
   - בחרו מיקום שרת (למשל `eur3` - אירופה).
4. בתפריט הימני: **Build -> Firestore Database -> Rules**, מחקו את התוכן הקיים והדביקו את התוכן של הקובץ `firestore.rules` מהפרויקט הזה, ולחצו **Publish**.
   (הכלל הזה פותח קריאה/כתיבה לכל מי שיש לו את הקישור לאתר - מתאים לשימוש פרטי בין אנשים שסומכים אחד על השני)
5. בתפריט הימני העליון, ליד "Project Overview", לחצו על סמל ההגדרות (⚙️) -> **Project settings**.
6. גללו למטה ל-**"Your apps"**, לחצו על סמל ה-Web (`</>`), תנו שם לאפליקציה (למשל `web`) ולחצו **Register app**.
7. Firebase יציג לכם אובייקט `firebaseConfig` עם ערכים כמו `apiKey`, `projectId` וכו'.
8. פתחו את הקובץ `js/firebase-config.js` בפרויקט הזה, והדביקו את הערכים במקום ה-placeholders (`YOUR_API_KEY` וכו').

## שלב 2: הרצה מקומית (אופציונלי, לבדיקה)

אפשר פשוט לפתוח את `index.html` בדפדפן. אם רוצים שרת מקומי קטן:

```bash
npx serve .
```

## שלב 3: העלאה ל-GitHub

```bash
cd maccabi-haifa-refund
git init
git add .
git commit -m "אתר מעקב החזר מנוי - מכבי חיפה"
```

לאחר מכן, ב-GitHub:
1. צרו repository חדש וריק (בלי README/gitignore) בכתובת https://github.com/new
2. חברו ודחפו:

```bash
git branch -M main
git remote add origin https://github.com/<שם-המשתמש-שלכם>/maccabi-haifa-refund.git
git push -u origin main
```

## שלב 4: פריסה ב-Vercel

1. היכנסו ל-https://vercel.com (לחשבון הקיים שלכם).
2. **Add New... -> Project**.
3. **Import** את ה-repository ש-`maccabi-haifa-refund` שדחפתם ל-GitHub.
4. מכיוון שזה אתר סטטי (ללא build), אפשר להשאיר את כל ההגדרות כברירת מחדל (Framework: **Other**) ולחצות **Deploy**.
5. תוך דקה תקבלו קישור חי (`https://maccabi-haifa-refund.vercel.app` או דומה) - שתפו אותו עם מי שצריך לעדכן נתונים.

מכל עדכון עתידי: פשוט `git push` ל-GitHub, ו-Vercel יפרוס אוטומטית את הגרסה החדשה.

## עדכון לוח המשחקים

הקובץ `js/games-data.js` מכיל את המשחקים הידועים נכון ל-26.7.2026 (עד תחילת ינואר 2027 - חלק מהמועדים "לא סופיים" ועדיין עשויים להשתנות).
משחקים נוספים (כולל שלב הפלייאוף בהמשך העונה) אפשר להוסיף ישירות מהאתר עם כפתור **"+ הוסף משחק"** - אין צורך לערוך קוד.

## הערת אבטחה

כרגע כל מי שמקבל את קישור האתר יכול לקרוא ולערוך את הנתונים (אין התחברות/סיסמה) - זה פשוט ומתאים לשימוש בין בני משפחה/חברים.
אם בעתיד תרצו הגנה חזקה יותר (למשל סיסמה משותפת או התחברות עם Google), אפשר להוסיף Firebase Authentication ולעדכן את `firestore.rules` בהתאם.
