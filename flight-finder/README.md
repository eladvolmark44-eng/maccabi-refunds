# ✈️ צייד סופ״שים

אתר שמוצא את **הסופ״ש הכי זול לטוס בו**. במקום לחפש לפי תאריך מסוים, בוחרים **חוקיות**, והאתר סורק את כל התאריכים שמתאימים לה בחודשים הקרובים, בכל היעדים שבחרתם, ומחזיר את האפשרויות מהזולה ליקרה.

דוגמאות לחוקיות:
- יוצאים ביום חמישי וחוזרים בשבת (2 לילות)
- יוצאים ביום רביעי או חמישי, 2-3 לילות
- סופ״ש ארוך של 3-4 לילות, רק טיסות ישירות, עד 800 ₪
- יציאה לא לפני 18:00 (כדי לא לקחת יום חופש) וחזרה לא לפני 20:00

## מה יש באתר

- **כמה יעדים בבת אחת.** מוסיפים יעדים בודדים או קבוצות מוכנות כמו "יוון וקפריסין" ו"מזרח אירופה". אם משאירים את רשימת היעדים ריקה, האתר מחפש בכל יעד.
- **שתי תצוגות.** "הזול לכל סופ״ש" מציגה את האפשרות הזולה ביותר בכל סופ״ש. "כל האפשרויות" מציגה כל צירוף של יעד ותאריכים.
- **קישורי השוואה.** לכל תוצאה יש קישורים ל-Aviasales, Google Flights, Skyscanner ו-Kayak עם אותם יעד ותאריכים, כדי להשוות בין האתרים בלחיצה.
- **בדיקת מחיר עדכני (אופציונלי).** כפתור שבודק מה המחיר ב-Google Flights כרגע.
- **שמירת החיפוש.** החיפוש נשמר בכתובת האתר. אפשר לשמור אותה כמועדף ולפתוח אותה כל כמה ימים כדי לקבל את המחירים העדכניים לאותה חוקיות.

## מאיפה המחירים?

אתרים כמו Google Flights ו-Skyscanner חוסמים סריקה אוטומטית, ולכן האתר משתמש ב-API של צוברי מחירים:

| מקור | למה משמש | עלות |
|---|---|---|
| [Travelpayouts](https://www.travelpayouts.com) (Aviasales) | הסריקה הרחבה: מחירים מחיפושים שנעשו ב-48 השעות האחרונות, בכל החודשים והיעדים | חינם |
| [SerpApi](https://serpapi.com) (Google Flights) | אופציונלי: בדיקת מחיר עדכני לתוצאה ספציפית | 100 חיפושים בחודש בחינם |

> מחירי Travelpayouts לקוחים ממטמון, ולכן הם מצוינים כדי למצוא **איזה סופ״ש** זול, אבל לפני הזמנה צריך לוודא את המחיר באתר עצמו. בשביל זה יש קישורי ההשוואה והכפתור "בדוק מחיר עדכני".

בלי מפתחות האתר רץ ב**מצב דמו** עם מחירים מומצאים, ומוצג באנר שמסביר את זה.

## הגדרה

1. נרשמים ל-Travelpayouts. אחרי ההרשמה מקבלים את הטוקן ב-**Profile → API token** (ונראה שגם מזהה שותף, Marker).
2. (לא חובה) נרשמים ל-SerpApi ומעתיקים את ה-API key.
3. מעתיקים את `.env.example` לקובץ `.env` וממלאים בו את המפתחות.

## הרצה מקומית

```bash
cd flight-finder
npm run dev      # http://localhost:3000
npm test
```

אין תלויות שצריך להתקין. מספיק Node 18 ומעלה.

## פריסה ב-Vercel

1. ב-Vercel יוצרים פרויקט חדש **מאותו repository**, ובשדה **Root Directory** בוחרים `flight-finder`.
2. ב-**Settings → Environment Variables** מוסיפים את `TRAVELPAYOUTS_TOKEN` (ואם רוצים גם `TRAVELPAYOUTS_MARKER` ו-`SERPAPI_KEY`).
3. לוחצים Deploy. הקבצים בתיקייה `api/` רצים אוטומטית כפונקציות שרת, והמפתחות לא נחשפים בדפדפן.

## מבנה

```
index.html, css/, js/          ממשק (סטטי)
api/search.js                  סריקה לפי חוקיות  ← /api/search
api/verify.js                  מחיר עדכני מ-Google Flights  ← /api/verify
lib/pattern.js                 לוגיקת החוקיות (ימי יציאה, לילות, שעות, טווח)
lib/providers/                 Travelpayouts, SerpApi, דמו
lib/links.js                   קישורי השוואה לאתרים
```
